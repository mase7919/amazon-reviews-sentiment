How to read this

  • This is a balanced 150-review sample: 50 POSITIVE / 50 NEUTRAL / 50 NEGATIVE (seed 6418).
  • An always-one-class classifier would score about 33% here, so 71.33% is not directly comparable to the earlier 98% binary number — both the sample distribution and the classification task changed (three classes vs two).
  • Watch NEUTRAL: because it is defined by absence of a clear lean, it is the class the model most often (38 of 50) failed to recognize.
